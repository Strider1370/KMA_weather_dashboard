# Docs Archive

Status: Archive index, current as of 2026-05-02.

This folder keeps historical design notes that are no longer the primary source of truth.

Current docs live at the top level of `docs/` and are linked from `docs/README.md`.

## Folders

- `superseded/`: older design notes whose current behavior has been merged into top-level docs.
- `research/`: useful research, idea notes, or scratch planning material that does not describe current implementation.
- `appendix/`: detailed parser appendices retained for reference but not treated as current behavior.
- `cleanup/`: records from the docs cleanup process.

## Reading Rule

When behavior conflicts, prefer the top-level current-state docs:

- `docs/architecture.md`
- `docs/backend-collectors.md`
- `docs/frontend-dashboard.md`
- `docs/map-overlays.md`
- `docs/weather-parsing.md`
