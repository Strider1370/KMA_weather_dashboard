# Mobile OPS Layout Plan

## Goal

모바일 브라우저에서 `/ops` 화면을 데스크탑과 다른 전용 레이아웃으로 제공한다.

핵심 목표:
- 모바일 전용 UI는 `/ops`에만 적용
- `/ground`는 모바일 대응 범위에서 제외
- 하단 고정 탭으로 `현재날씨 / 예보 / 지도` 전환
- `WarningList`는 `현재날씨` 탭 내부 최상단에 항상 표시
- 모바일 TAF는 `table` 기본, `v3` 보조, `v2 timeline` 비노출

## Scope

포함:
- 모바일 전용 `/ops` 레이아웃
- 하단 탭 네비게이션
- 현재날씨 탭 내부 Warning 패널
- 모바일 전용 TAF 표시 방식
- 지도 패널 모바일 최적화
- 탭 스와이프 / pull-to-refresh / 탭 전환 애니메이션

제외:
- `/ground` 모바일 레이아웃 작업
- 백엔드 API 변경
- 데이터 payload 구조 변경
- 데스크탑 `/ops` 전면 개편

## Route Rules

- 모바일 전용 레이아웃은 `/ops`에서만 적용한다.
- `/ground`는 기존 레이아웃을 유지한다.
- `/test`는 이번 범위에서 제외하고 기존 동작을 유지한다.

## Layout Overview

모바일 `/ops` 화면은 3개 영역으로 구성한다.

1. 상단 영역
2. 본문 영역
3. 하단 고정 탭 바

### Top Area

항상 표시:
- 공항 선택 드롭다운
- 설정 버튼

규칙:
- 헤더에는 `WarningList`를 두지 않는다
- `ground` 전환 버튼은 모바일에서 숨김

### Main Content

한 번에 한 패널만 표시한다.

패널 종류:
- `현재날씨`
- `예보`
- `지도`

원칙:
- 본문은 세로 스크롤 중심
- 한 화면에 하나의 과업만 집중
- 지도와 예보는 탭으로 분리해 충돌을 줄인다

### Bottom Tab Bar

하단 고정 탭:
- 현재날씨
- 예보
- 지도

규칙:
- 모바일 `/ops` 진입 기본 탭은 `현재날씨`
- 마지막 선택 탭은 저장 가능
- 하단 탭 바 높이만큼 본문 하단 여백 확보
- 텍스트 탭 우선, 아이콘은 사용하지 않음

## Panel Design

### Current Weather Tab

표시 대상:
- `WarningList`
- 모바일 전용 `MetarCard`

원칙:
- `WarningList`는 경고 유무와 관계없이 항상 최상단 표시
- 비행조건 패널을 상단에 배치
- 하위 지표는 카드형 그리드로 배치
- 현재 구현 기준 하위 지표는 `시정 / 운고 / 바람 / 측풍 / 현재날씨 / 온도 / 일강수량 / QNH`
- 헤더 오른쪽에는 `일출 / 일몰`을 표시

### Forecast Tab

기본 보기:
- `table` 토글 라벨은 `카드`

보조 보기:
- `v3` 토글 라벨은 `표`

숨김:
- `v2 timeline`

#### Mobile Table Direction

모바일 `table`은 데스크탑의 넓은 표를 축소해서 그대로 보여주지 않는다.

대신 시간 구간 중심의 세로 카드 리스트로 재구성한다.

구성:
- 카드 상단에 시간 범위
- 좌측 세로 타임라인 바는 카드와 독립적으로 렌더
- 카드 자체는 균등 높이 유지

각 카드 유지 정보:
- 비행조건 패널
- 시정
- 바람
- 운고
- 날씨

강조 규칙:
- IFR/LIFR는 비행조건 패널 색상으로 강조
- 시정/운고는 카테고리 tint 적용
- 강풍은 빨간 점선 강조
- 특이기상/강수는 날씨 카드에서 outline/tint 적용
- 좌측 타임라인 바는 시간 길이에 비례한 높이 사용
- 좌측 눈금은 첫 구간과 날짜 변경 시점에 날짜를 함께 표시

#### Mobile V3 Direction

`v3`는 세로 스크롤 테이블형 보조 보기로 사용한다.

형태:
- `시간 / 날씨 / 바람 / 운고 / 시정` 컬럼
- 각 시간대가 한 줄(row)씩 아래로 쌓임
- 첫 행과 날짜 변경 시점에 날짜 마커 표시

강조 규칙:
- 시정/운고 셀은 `table`과 같은 tint 규칙 적용
- 바람 셀은 강풍 시 빨간 점선 적용
- 날씨 셀은 특이기상/강수 조건에 따라 점선 또는 tint 적용

### Map Tab

표시 대상:
- `InteractiveMap`

원칙:
- 지도 조작 영역 최대 확보
- 핵심 토글만 우선 노출
- 범례는 기존처럼 지도 내부 배치 유지

모바일 고려사항:
- 탭 진입 시 지도 리사이즈 보정
- 첫 진입 시 전국 기준으로 시작하되, 이후 줌/이동 중 자동 복귀 금지
- `Invalid LatLng` 방어 로직 유지

## Gestures

- 좌우 스와이프로 `현재날씨 / 예보 / 지도` 탭 이동
- 아래로 당기면 pull-to-refresh 힌트 표시 후 새로고침
- 지도/버튼/입력 조작과 충돌하는 영역은 gesture 대상에서 제외
- 탭 전환 시 좌우 방향 기반 진입 애니메이션 사용

## Component Impact

### App.jsx

- 모바일 + `/ops` 조건 분기 추가
- 하단 탭 네비게이션 추가
- 탭별 단일 패널 렌더링 구성
- 모바일에서는 `ground` 전환 버튼 숨김
- 탭 스와이프, pull-to-refresh, 탭 전환 애니메이션 상태 관리

### MetarCard.jsx

- 모바일 전용 현재날씨 레이아웃 추가
- `WarningList` 아래에서 비행조건 패널 + 카드 그리드 구성
- 일출/일몰, 일강수량, QNH 카드 반영

### TafTimeline.jsx

- 모바일에서 `table / v3`만 노출
- 모바일 기본값 `table`
- 모바일 전용 `table` 카드형 마크업 추가
- 모바일 전용 `v3` 세로 테이블 마크업 추가
- `v2 timeline` 모바일 비노출

### InteractiveMap.jsx

- 탭 진입 시 `invalidateSize()` 보정
- 모바일 초기 전국 위치 보정
- 비정상 `LatLng` 방어 로직 유지

### App.css

- 모바일 `/ops` 전용 레이아웃 규칙 추가
- 상단/본문/하단탭 3영역 구조
- 하단 고정 탭 스타일
- 모바일 TAF 카드/표 스타일
- pull-to-refresh 힌트 스타일
- 탭 전환 애니메이션 스타일
- 지도 높이 조정 규칙

## Technical Risks

- Leaflet 지도가 탭 전환 후 잘못된 크기로 렌더될 수 있음
- `table` 카드 높이와 좌측 타임라인 바 비례 높이의 시각적 동기화가 어긋날 수 있음
- 모바일/데스크탑 TAF view state가 섞이면 UX가 혼란스러울 수 있음
- 스와이프 제스처가 내부 스크롤/지도 조작과 충돌할 수 있음

## Validation Checklist

- 모바일 `/ops`에서만 전용 탭 UI가 보이는가
- `/ground`는 기존 동작을 유지하는가
- 현재날씨 탭에서 `WarningList`가 항상 표시되는가
- 하단 탭 전환이 정상 동작하는가
- 좌우 스와이프로 탭 전환이 가능한가
- 아래로 당겨 새로고침 힌트와 reload가 동작하는가
- 모바일 TAF 기본값이 `table`인가
- 모바일에서 `v2 timeline`이 노출되지 않는가
- `v3` 보조 보기가 정상 전환되는가
- `table` 좌측 타임라인 바가 시간 비례 높이로 보이는가
- 카드/V3 양쪽 모두 시정/운고/바람/날씨 조건 강조가 동작하는가
- 지도 탭 진입 시 Leaflet 렌더 크기가 정상인가
- 하단 탭 바가 본문 내용을 가리지 않는가
- 데스크탑 `/ops` 레이아웃이 유지되는가
